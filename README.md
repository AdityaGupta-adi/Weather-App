A modern Weather App built using HTML, CSS and JavaScript with real-time weather information powered by the OpenWeather API.

## ✨ Features

- 🌍 Real-Time Weather
- 📍 Current Location Support
- 🎤 Voice Search
- 🌙 Dark & Light Mode
- 🌡️ Celsius / Fahrenheit
- 📅 5-Day Forecast
- 🕒 24-Hour Forecast
- 🌿 Air Quality Index (AQI)
- ⭐ Favorite Cities
- 🕘 Recent Searches
- 💾 Local Storage Support
- 📱 Fully Responsive UI
- 🚀 Progressive Web App (PWA)

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- OpenWeather API
- Local Storage
- GitHub Pages
